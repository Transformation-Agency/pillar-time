# UX Readiness Pass 16: Planner Task Archive Confirmation

Date: 2026-06-24
Branch: `ux-production-readiness-pass-16`

## Finding

Planner task archiving was still a one-click action. Earlier passes added confirmation to Today’s Three removal and Reminder archiving, but the Task Backlog still allowed a misclick to hide a task from the active planning surface immediately.

Impact: users can accidentally remove work from the ranking engine and Today suggestions without a chance to stop, which undermines trust in the planning system.

## Fix

- Added a confirmation before archiving Planner tasks.
- Wrote copy that explains the visible effect: the task leaves the active backlog and stops appearing as a Today candidate.
- Extended the planning-removal guardrail test so task archiving cannot regress to a direct mutation handler.

## Verification

- `npm test`
- `npm run build`

## Recommended Follow-Up

Add rendered interaction tests for Planner task archive Cancel/OK behavior alongside the Today and Reminder confirmation flows.
