# UX Readiness Pass 21

## Scope
- Area: onboarding and Settings local dependency installers.
- Goal: make local installs explicit before starting system-changing or download-heavy actions.

## Finding
- The FFmpeg install buttons immediately started a Homebrew-backed local install.
- The Whisper model buttons immediately started a local model download.
- The buttons were labeled, but there was no final confirmation explaining what would happen on this Mac.

## Change
- Added a consent prompt before FFmpeg install in both onboarding and Settings.
- Added a consent prompt before Whisper model download in both onboarding and Settings.
- The prompts explain the local side effect and why Pillar Time is asking.
- Added a guardrail test that requires both install surfaces to keep these prompts.

## Verification Plan
- `npm test`
- `npm run build`

## Follow-Up
- In packaged-app QA, trigger each prompt and cancel it to confirm no install/download starts after cancellation.
