# UX Readiness Pass 23

## Scope
- Area: Linear connector modal.
- Goal: prevent silent loss or ambiguity around unsaved Linear API key/setup edits.

## Finding
- A user could paste a Linear API key or toggle the connector enable setting, then close the modal with X, backdrop click, Cancel, or Open Linear.
- There was no warning that those edits had not been saved.
- The modal could also retain typed key text in component state after a close, making Cancel feel less definite than it should.

## Change
- Added a shared Linear modal close handler.
- The handler detects unsaved API key text or enable-state changes.
- It asks before discarding unsaved connector edits.
- On confirmed discard, it resets the API key field and enable toggle back to the saved connector state.
- X, backdrop, Cancel, and Open Linear now all use the same close path.

## Verification Plan
- `npm test`
- `npm run build`
