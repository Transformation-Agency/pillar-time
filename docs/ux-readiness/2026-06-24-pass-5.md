# UX Readiness Pass 5: Day Plan Preflight

Date: 2026-06-24
Branch: `ux-production-readiness-pass-5`

## Finding

The Today page’s `Generate Day Plan` button was safe to use with partial setup, but first-run users had to infer that from the rest of the app. With Calendar, Linear, or model setup missing, the action could feel like it might fail instead of producing a deterministic plan with coverage notes.

Impact: a real user may avoid the main action because the prerequisites are unclear, or may distrust the output because missing connectors are not named before generation.

## Fix

- Added a compact Today preflight line under the page header.
- When setup is incomplete, it says generation works with available local context and names missing connectors.
- When setup is complete, it says generation will use Calendar, Linear, model synthesis, and local context.
- Added a guardrail for the first-run copy.

## Verification

- `npm test`
- `npm run build`

## Recommended Follow-Up

Add a rendered UI test for the preflight in three states: no connectors, Calendar/Linear without model, and all ready.
