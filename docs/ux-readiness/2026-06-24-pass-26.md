# UX Readiness Pass 26

## Scope
- Area: Help/update menu accessibility.
- Goal: align menu semantics with the interactive controls inside the menu.

## Finding
- The Help/update popover declared `role="menu"`.
- Its update actions were plain buttons without `role="menuitem"`.
- This can make the menu harder to understand for assistive technology users, especially around update/restart recovery actions.

## Change
- Added `role="menuitem"` to Help menu update actions:
  - Check for Updates
  - Install Update
  - Restart to Update
  - Open Update Settings
- Added a guardrail test so the role pairing stays intact.

## Verification Plan
- `npm test`
- `npm run build`

## Follow-Up
- In browser QA, tab into the Help menu and confirm focus order remains predictable with the role changes.
