# UX Readiness Pass 17: Delivery Schedule Select Labels

Date: 2026-06-24
Branch: `ux-production-readiness-pass-17`

## Finding

Delivery schedule controls in the home delivery card and onboarding schedule step used icon-wrapped native selects without accessible labels. Visually, the fields are understandable from nearby text, but assistive technology users could encounter unlabeled dropdowns for frequency, weekly day, and timezone.

Impact: first-run delivery setup and later schedule adjustment are harder to complete reliably with a screen reader or keyboard-first workflow.

## Fix

- Added explicit `aria-label` text to delivery frequency, delivery day, and delivery timezone selects.
- Added separate labels for the onboarding schedule controls so both surfaces are covered.
- Added a guardrail test for these labels.

## Verification

- `npm test`
- `npm run build`

## Recommended Follow-Up

Add rendered accessibility checks for the full delivery setup flow, including switching Daily to Weekly and verifying the weekly-day select is announced.
