# UX Readiness Pass 4: Generation Completion Copy

Date: 2026-06-24
Branch: `ux-production-readiness-pass-4`

## Finding

The generation progress screen treated any completed intelligence run as delivered to Telegram. That was misleading when Telegram was disabled, skipped, failed, or had an ambiguous acknowledgement timeout.

Impact: a user can watch a run finish, see “Brief delivered” / “sent to Telegram,” and lose trust when the actual delivery state is “saved only” or “check Telegram.”

## Fix

- Added delivery-aware completion copy for the generation screen.
- Executive day runs now say the day plan was saved in Pillar Time.
- Intelligence runs now distinguish:
  - delivered to Telegram
  - saved but Telegram acknowledgement ambiguous
  - saved in Pillar Time only
- Added a regression guardrail for the “Check Telegram before sending it again” copy.

## Verification

- `npm test`
- `npm run build`

## Recommended Follow-Up

Add a UI fixture test that renders `GeneratingBrief` with each delivery state: delivered, skipped, failed, pending acknowledgement, and no Telegram configured.
