# UX Readiness Pass 24

## Scope
- Area: X API and Reddit OAuth connector modals.
- Goal: prevent accidental loss of pasted social API credentials during setup.

## Finding
- Users could paste an X bearer token or Reddit OAuth credentials, then close the modal with X, backdrop click, or Cancel.
- The text would be discarded without warning.
- This is painful in first-run setup because API credentials are often copied from another browser window and may be hard to recover.

## Change
- Added a shared X setup close handler that detects unsaved bearer-token text.
- Added a shared Reddit setup close handler that detects unsaved client ID, client secret, grant type, or device ID edits.
- X, backdrop, and Cancel now all use the guarded close path for both modals.
- Confirmed discard resets credential fields back to their saved/default state.
- Added guardrail tests for both modals.

## Verification Plan
- `npm test`
- `npm run build`

## Follow-Up
- In browser QA, paste fake X and Reddit credential text, click Cancel, reject the discard prompt, and confirm each modal stays open with the text intact.
