# UX Readiness Pass 12: Textarea Guidance Rendering

Date: 2026-06-24
Branch: `ux-production-readiness-pass-12`

## Finding

The shared `TextArea` component accepted only `label`, `value`, `onChange`, and `rows`. Several first-run and recovery flows passed placeholder guidance into it, but those props were silently dropped:

- Today context intake.
- Onboarding operating manual.
- Perspective request setup.

Impact: the app’s most open-ended text fields lost the examples that explain what a real user should type or paste. That makes first-run setup and “add missed context and regenerate” feel more blank than intended.

## Fix

- Updated `TextArea` to forward remaining props to the underlying `<textarea>`.
- Added a guardrail test proving the component preserves helper props and that the key guidance placeholders remain present.

## Verification

- `npm test`
- `npm run build`

## Recommended Follow-Up

Add rendered form tests for onboarding and Today context intake to assert that helper text is visible in the browser, not only present in source.
