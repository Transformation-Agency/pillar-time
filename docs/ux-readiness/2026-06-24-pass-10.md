# UX Readiness Pass 10: Planning Action Confirmations

Date: 2026-06-24
Branch: `ux-production-readiness-pass-10`

## Finding

Two planning-critical actions were immediate one-click changes:

- `Remove` on Today’s Three hid a protected commitment from the day plan.
- `Archive` on reminders removed a reminder from the active reminder list and stopped future nudges.

These are soft deletes in the backend, but the visible effect is still abrupt. A real user could misclick while scanning the day and lose confidence that Pillar Time is protecting the right commitments.

Impact: accidental removal from the active planning surface is easy, and the user receives no chance to stop before the item disappears.

## Fix

- Added a confirmation before removing a commitment from Today’s Three.
- Added a confirmation before archiving a reminder.
- Wrote the confirmation copy to explain the visible consequence and avoid implying that the underlying task/source item is deleted.
- Added a source-level guardrail test so these actions do not regress to direct mutation handlers.

## Verification

- `npm test`
- `npm run build`

## Recommended Follow-Up

Add rendered interaction tests that click Cancel and OK on these confirmations and assert the correct API calls are or are not made.
