# UX Readiness Pass 18

## Scope
- Area: Brief Setup structure builder.
- Goal: remove dead or ambiguous section action controls before release.

## Finding
- The section action row exposed icon-only copy and edit buttons with no handlers.
- The remove section button was icon-only and deleted a configured brief section immediately.
- Move up/down buttons were visually understandable but had no accessible labels for keyboard or screen-reader users.

## Change
- Disabled the unavailable copy/edit controls and gave them labels plus explanatory titles.
- Added a confirmation step before removing a brief section.
- Added labels and titles for remove, move up, and move down controls.
- Added a guardrail test so the inert icon-only buttons do not return unnoticed.

## Verification Plan
- `npm test`
- `npm run build`

## Follow-Up
- Run a rendered keyboard pass through Brief Setup before release to confirm focus order and disabled control presentation feel right in the packaged app.
