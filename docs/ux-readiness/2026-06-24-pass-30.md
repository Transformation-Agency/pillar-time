# UX Readiness Pass 30

## Scope
- Area: Today page suggestion actions and quick capture.
- Goal: make the command-center actions visibly recoverable when a save fails.

## Finding
- Today suggestion actions (`Accept`, `Not Today`, `Incorrect`) directly mutated backend state without local success or failure feedback.
- Quick capture also used promise chaining and cleared only on success, but failures produced no visible message.
- These actions shape Today’s Three and the day-plan input set, so silent failure makes it hard to trust whether the app acted.

## Change
- Added local success/failure feedback to each suggestion card.
- Converted suggestion accept and feedback actions to `async` error-handled flows.
- Added local success/failure feedback to Today quick capture.
- Preserved quick-capture text on failure so the user can retry.
- Added guardrail tests for Today suggestion and quick-capture feedback.

## Verification Plan
- `npm test`
- `npm run build`

## Follow-Up
- Browser QA should click Today suggestion actions and submit quick capture with successful and failed backend saves to confirm visible feedback.
