# UX Readiness Pass 25

## Scope
- Area: model provider and Telegram delivery setup modals.
- Goal: prevent accidental loss of pasted model and Telegram credentials.

## Finding
- Users could paste a model provider API key, change a model/base URL, or edit Telegram bot delivery settings, then close the modal with X, backdrop click, or Cancel.
- Those edits were discarded without warning.
- First-run setup often involves copying credentials from another app or browser tab, so silent discard makes recovery frustrating and erodes trust.

## Change
- Added a shared close handler for model provider setup.
- Added a shared close handler for Telegram delivery setup.
- Both handlers detect unsaved credential/config edits, ask before discarding, and reset the form to saved state after confirmed discard.
- X, backdrop, and Cancel now all use the guarded close path for both modals.
- Added guardrail tests for both modal families.

## Verification Plan
- `npm test`
- `npm run build`

## Follow-Up
- In browser QA, paste fake model and Telegram credentials, click Cancel, reject the discard prompt, and confirm each modal stays open with the text intact.
