# UX Readiness Pass 7: Onboarding Reopen Confirmation

Date: 2026-06-24
Branch: `ux-production-readiness-pass-7`

## Finding

Settings had a `Run onboarding` button that immediately reset first-run onboarding state. The action is recoverable, but it sends the user back to the welcome flow and can look like a destructive setup reset.

Impact: a user can accidentally leave the normal Settings context and wonder whether saved connectors, brief settings, or local data were reset.

## Fix

- Renamed the action to `Reopen onboarding`.
- Added a confirmation prompt before resetting onboarding state.
- The prompt explains that saved settings, connectors, and local data stay in place.
- Added a guardrail preventing the old immediate `Run onboarding` affordance from returning.

## Verification

- `npm test`
- `npm run build`

## Recommended Follow-Up

Replace the native confirmation with an in-app modal if Settings later gains a broader reset/recovery command group.
