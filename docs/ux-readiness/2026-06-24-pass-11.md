# UX Readiness Pass 11: Accessible Labels For High-Use Controls

Date: 2026-06-24
Branch: `ux-production-readiness-pass-11`

## Finding

Several high-use controls depended on placeholder text, table position, or an adjacent icon to explain their purpose:

- Today quick capture.
- Planner important-date title/start/end fields.
- Source and brief search fields.
- Linear issue state and comment cells.
- Onboarding starter commitment.

Impact: keyboard and screen-reader users can encounter unnamed or ambiguous controls in the exact places where they need to capture commitments, search saved work, and update connected systems.

## Fix

- Added explicit `aria-label` attributes to the high-traffic unlabeled inputs and table controls.
- Kept the visual layout unchanged.
- Added a guardrail test for the labels most likely to regress during future UI edits.

## Verification

- `npm test`
- `npm run build`

## Recommended Follow-Up

Run a rendered accessibility pass with axe or an equivalent browser harness to find remaining unlabeled controls in lower-traffic setup screens.
