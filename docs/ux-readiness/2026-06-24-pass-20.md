# UX Readiness Pass 20

## Scope
- Area: Settings connector picker.
- Goal: remove a dead-end from the Add connector modal.

## Finding
- The Add connector modal offered an ElevenLabs audio tile.
- Clicking it only closed the modal, leaving users at the top of Settings with no obvious next step.
- This was especially confusing because other connector tiles open the relevant setup modal directly.

## Change
- Added a real Audio Briefs settings target in Settings.
- Changed the ElevenLabs audio tile to close the picker and scroll to Audio Briefs.
- Updated the tile copy from passive guidance to a clear jump action.
- Added a guardrail test so this tile cannot regress to a close-only action.

## Verification Plan
- `npm test`
- `npm run build`

## Follow-Up
- In browser QA, click Add connector -> ElevenLabs audio and confirm focus/scroll behavior feels obvious in the live app window.
