# UX Readiness Pass 19

## Scope
- Area: desktop update restart flow.
- Goal: prevent an unexpected app quit/restart from losing unsaved setup or planning text.

## Finding
- The update banner, Help menu, and Settings update panel all called the desktop restart action directly once an update was installed.
- A user could click Restart while editing onboarding, settings, or planning text and lose unsaved work without a final warning.

## Change
- Centralized restart protection in the desktop update hook.
- The app now asks for confirmation before restarting to finish an update.
- The confirmation copy explains that unsaved text or in-progress setup can be lost.
- Added a guardrail test to ensure restart does not return to a direct call.

## Verification Plan
- `npm test`
- `npm run build`

## Follow-Up
- In a packaged-app pass, confirm the native restart still proceeds after confirmation and that the dialog appears from the update banner, Help menu, and Settings.
