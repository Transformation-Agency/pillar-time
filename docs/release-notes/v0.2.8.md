# Pillar Time v0.2.8

Adds in-app feedback from the Help menu so bugs, feature requests, and product notes can be sent directly to the Pillar Time issue tracker.

## Improvements
- Add Help → Send Feedback.
- Support bug, feature request, and general feedback submissions.
- Include route, platform, app version, user agent, and timestamp context in feedback reports.
- Support optional screenshot upload or paste, with preview and remove controls.
- Route feedback to the shared Transformation Agency feedback server with `product: pillar-time`.

- Apple Silicon Mac: `Pillar.Time_0.2.8_aarch64.dmg`
- Intel Mac: `Pillar.Time_0.2.8_x64.dmg`
