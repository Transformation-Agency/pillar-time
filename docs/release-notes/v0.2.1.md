# Pillar Time v0.2.1

Executive calendar intelligence, approval-gated schedule blocks, and Today context intake.

## Fixes
- Re-centers the default Generate action on the executive-day workflow instead of the intelligence/news workflow.
- Adds deterministic calendar classification for all-day events, timed events, primary calendars, shared/subscribed calendars, ownership, and blocking visibility.
- Builds proposed calendar blocks around hard commitments without writing to Google Calendar during generation.
- Adds approval-gated Calendar and Linear execution for generated actions.
- Surfaces proposed calendar tiles, approve-calendar flow, and context-aware Today timeline data.
- Adds Today context intake for identity statement, standing commitments, and running to-do items, with paste/type and text-file import.
- Keeps cached intelligence artifacts out of Today generation and timeline state.
- Improves no-model fallback so executive day planning completes even when the model connector is not ready.
- Tightens connector/source UX with Linear empty-key validation, source deletion confirmation, and Google Calendar disconnect confirmation.
- Updates release-readiness notes and guardrail tests for executive calendar planning, runtime separation, and first-run UX.
