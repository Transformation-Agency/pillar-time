# Pillar Time v0.1.9

Connector, planning, reminder, source cleanup, audio, and updater fixes from Anna's feedback.

## Fixes
- Moves Linear setup into Settings and onboarding with local saved credentials, while keeping `LINEAR_API_KEY` as a fallback.
- Prioritizes high-priority Planner tasks in the existing Today suggestions without adding a separate Today panel.
- Adds date ranges for Important Dates and window-based sporadic reminders.
- Removes Sources and Perspective Lenses from the user-facing app and stops shipping default source catalogs.
- Improves brief audio playback diagnostics and verifies generated MP3 files before playback.
- Adds desktop updater diagnostics and validates the updater manifest before publishing.
- Fixes full-width header navigation so links no longer require horizontal scrolling on desktop.
