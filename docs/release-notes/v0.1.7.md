# Pillar Time v0.1.7

Calendar selection and desktop fixes.

## Fixes

- Google Calendar event fetch now respects the connector's current calendar
  selection. When the source is in "selected" mode it follows the live selected
  calendars instead of a stale cached list, so deselecting a calendar (for
  example a shared calendar) immediately stops its events from appearing.
- Pillar Time uses its own local backend port, so it no longer collides with
  Pillar Brief. Both apps can run at the same time, each showing its own window
  instead of Time loading Brief's content.
- After connecting Google Calendar, the browser tab now just shows a "connection
  complete, close this tab" page instead of opening the Pillar Time web app in
  the browser. The desktop app picks up the connection automatically.
