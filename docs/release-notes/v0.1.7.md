# Pillar Time v0.1.7

Fixes calendars you deselected still showing up in your brief.

## Fixes

- Google Calendar event fetch now respects the connector's current calendar
  selection. When the source is in "selected" mode it follows the live selected
  calendars instead of a stale cached list, so deselecting a calendar (for
  example a shared calendar) immediately stops its events from appearing.
