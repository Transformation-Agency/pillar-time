# Pillar Time v0.2.6

Fixes Today commitment duplication and hardens desktop packaging so local settings survive app replacement.

## Fixes
- Merge duplicate Today's Three commitments when the same Linear-backed item is accepted more than once.
- Make Remove and Done clear duplicate commitment rows together instead of leaving lookalike rows behind.
- Show only active commitments in Today's Three.
- Require Node 24 for desktop packaging so the bundled backend supports `node:sqlite`.
- Preserve user connector/settings data in the external app data directory during app replacement.

- Apple Silicon Mac: `Pillar.Time_0.2.6_aarch64.dmg`
- Intel Mac: `Pillar.Time_0.2.6_x64.dmg`
- Windows: `Pillar.Time_0.2.6_x64-setup.exe`
