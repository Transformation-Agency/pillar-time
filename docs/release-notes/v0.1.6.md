# Pillar Time v0.1.6

Fixes Google Calendar connection completing with "The OAuth state did not match."

## Fixes

- Parse `application/x-www-form-urlencoded` request bodies on the local server.
  The auth broker posts the OAuth result back as an HTML form, but the server
  only parsed JSON, so the returned state and token never arrived and the
  connection failed state validation. Added the `express.urlencoded()` body
  parser (matching Pillar Brief), so Google Calendar now connects end to end.
