# Pillar Time v0.2.2

Combined day-plan and intelligence generation with fresh Linear context.

## Fixes
- Makes Today generation produce one combined executive-day run that refreshes Calendar, Linear, and configured intelligence sources together.
- Adds fresh Linear assigned/open issues to executive ranking and proposed time allocation.
- Stores Linear context and intelligence context in the same executive-day artifact.
- Adds a Today `View Brief` button that opens the Intelligence view for the generated run.
- Expires stale `running` workflow rows so old delivery-state failures cannot leave the app looking hung.
- Adds a client polling timeout so the generation screen does not spin forever if completion polling is interrupted.
