# Pillar Time v0.2.5

Branding refresh for the Pillar Time desktop app.

## Fixes
- Replaces the old app icon with the new purple Pillar Time mark.
- Uses the new Pillar Time icon in the header lockup instead of the Pillar Brief icon.
- Fixes the logo transparency so the app icon and header logo no longer show black corners.
- Updates the header wordmark so “Time” appears in the new purple brand color.
- Regenerates macOS, Windows, iOS, and Android icon assets from the transparent source.

## Downloads
- Apple Silicon Mac: `Pillar.Time_0.2.5_aarch64.dmg`
- Intel Mac: `Pillar.Time_0.2.5_x64.dmg`
- Windows: `Pillar.Time_0.2.5_x64-setup.exe`
