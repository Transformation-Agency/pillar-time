Ships Anna's latest desktop feedback pass with clearer onboarding recovery, better planning controls, and more reliable local workflows.

- Fix Settings → Reopen onboarding so it immediately resets first-run state and renders onboarding again.

- Make dismissed Highest Leverage Today suggestions disappear immediately while preserving backend feedback penalties.
- Clarify Today's Three completion and removal copy.

- Persist assigned open Linear issues into the Planner backlog during Linear refresh.
- Add edit and archive/delete actions for Important Dates.
