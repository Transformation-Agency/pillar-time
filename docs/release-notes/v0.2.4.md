# Pillar Time v0.2.4

UX-readiness release focused on first-run recovery, setup clarity, and visible save feedback.

## Fixes
- Improve Google Calendar write-scope recovery and approval-state copy.
- Clarify Telegram delivery states when acknowledgement is ambiguous or delayed.
- Add safer confirmation flows for onboarding, setup discard, local dependency installs, update restart, and planning removals.
- Improve modal accessibility with close labels and dialog semantics.
- Surface Settings credential save failures inside the relevant setup modals.
- Surface Planner, Reminder, Meeting, Today suggestion, and quick-capture save results instead of failing silently.
- Improve backend connection retry and first-run setup health messaging.
