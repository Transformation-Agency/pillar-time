# Pillar Time v0.1.5

Fixes Google Calendar connection failing with "The OAuth state did not match."

## Fixes

- Google Calendar OAuth now opens in a single browser flow. The consent URL
  (auth broker + Google) is allowlisted for the in-app external-URL opener, and
  the redundant server-side browser launch was removed. Previously the URL
  opened twice, so the second flow's callback failed state validation and showed
  "The OAuth state did not match."
