# Pillar Time v0.1.10

Executive-day workflow, runtime separation, and first-run UX hardening.

## Fixes
- Makes the default Generate action create an executive day plan instead of an intelligence/news report.
- Adds a deterministic executive-day fallback when the model connector is not ready, so planning no longer stops at synthesis.
- Separates Pillar Time runtime ports and environment variables from Pillar Brief and Pillar Law.
- Prevents Linear from appearing enabled when no API key or saved credential is available.
- Improves onboarding copy for Google Calendar, operating-manual context, reminders, and setup recovery.
- Clarifies reminder and review states, including master-reminder gating and human-readable review cadence labels.
- Tightens desktop header navigation and button contrast for production UX readiness.
- Adds UX readiness audit notes and guardrail tests for runtime separation and first-run flows.
