# Pillar Time v0.1.4

This release fixes Google Calendar connection and ships the first fully signed,
notarized desktop build with working in-app updates.

## Highlights

- Fixed Google Calendar connection failing with "client_secret is missing" by
  routing OAuth through the hosted auth broker (no client secret needed in the app).
- Added a dedicated Tauri updater signing key for Pillar Time and enabled signed
  updater artifacts so in-app updates verify correctly.
- First signed and notarized macOS release (Apple Silicon + Intel) and signed
  Windows installer produced by CI, with a published `latest.json` updater manifest.

## Downloads

- Intel Mac: `Pillar.Time_0.1.4_x64.dmg`
